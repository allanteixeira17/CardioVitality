# Pasta de Orientações da Clínica

Esta pasta é onde o operador deve colocar os arquivos específicos da sua clínica.
O assistente lerá esses arquivos automaticamente e priorizará as informações aqui contidas.

## Arquivos Sugeridos

| Arquivo | Conteúdo |
|---|---|
| `convenios.md` | Lista de planos e convênios aceitos |
| `especialidades.md` | Especialidades disponíveis e médicos |
| `horarios.md` | Dias e horários de funcionamento |
| `preparo-exames.md` | Instruções de preparo para exames e consultas |
| `valores.md` | Tabela de valores para consultas particulares |
| `protocolos.md` | Protocolos internos de atendimento |
| `faq.md` | Perguntas frequentes específicas da clínica |
| `contatos.md` | Contatos e telefones e celular da clínica |
| `index.html` | Mais informações que não tenha nos arquivos acima |


## Como usar

1. Crie os arquivos nesta pasta com as informações da sua clínica
2. No início de cada sessão, informe ao assistente: "Use os arquivos da pasta orientacoes/"
3. O assistente lerá os arquivos e os usará em todas as respostas

## Formato recomendado

Use arquivos `.md` (Markdown) ou `.txt` simples.
Quanto mais claro e estruturado o conteúdo, melhores serão as respostas do assistente.
